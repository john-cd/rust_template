# my_lib

Starter library with configuration, errors, domain models, and service modules.

```rust
assert_eq!(my_lib::greeting("Alice"), "Hello, Alice from my_lib!");
```

Run `cargo test -p my_lib`, `cargo run -p my_lib --example greeting`, and `cargo bench -p my_lib` from the workspace root.
