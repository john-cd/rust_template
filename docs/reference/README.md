# Reference

Document stable project interfaces and configuration here. Useful topics include workspace conventions, lint policy, nextest profiles, dependency checks, and CI behavior.

The source configuration currently lives in the root `Cargo.toml`, `Makefile.toml`, `deny.toml`, `.cargo/config.toml`, `.config/nextest.toml`, and `.github/workflows/`. Runtime logging is initialized in the CLI crate; see the [logging guide](../guides/logging.md).
