# Documentation

Project documentation is organized by audience and purpose:

- [Architecture](architecture/README.md): system structure and design decisions.
- [Development](development/README.md): local setup and contributor workflow.
- [Guides](guides/README.md): task-oriented instructions.
- [Reference](reference/README.md): configuration and tooling details.
- [Requirements](requirements.md): template constraints and adoption assumptions.

The [contributor guide](../CONTRIBUTING.md) covers setup and validation.
The [tools crate](../tools/README.md) provides portable development commands.
Public-facing pages live in the [Zola website](../website/README.md).
